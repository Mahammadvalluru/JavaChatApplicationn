A multi-client real-time chat application built in Java using Socket 
Programming, Multithreading, and OOP principles. Supports 10+ concurrent 
TCP/IP connections with thread-safe message broadcasting and fault-isolated 
client session management.

Tech Stack: Java | Socket Programming | Multithreading | OOP | TCP/IP

Key features:
- Concurrent multi-client architecture (10+ simultaneous connections)
- Thread-safe synchronized message broadcasting
- Independent thread per client for fault isolation
- Clean OOP design with encapsulation and abstraction
